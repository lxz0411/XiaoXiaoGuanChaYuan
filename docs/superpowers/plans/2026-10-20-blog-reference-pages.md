# 第三篇博客站内资料页实施计划

**目标：** 将第三篇的PubMed论文和PACE建议替换为站内资料页，分别保留医学文献库与议会文件网站的视觉特征，提供英文/中文切换。

**设计：** 使用两个独立Vue页面、共用一个简短翻译工具栏。PubMed采用蓝灰色机构页头、检索条、文献元数据、结构化摘要和右侧记录导航；PACE采用欧洲蓝页头、机构标识、文档导航、建议编号和编号段落。参考NLM公布的2010年摘要页截图，避免加入晚于游戏年代的相关研究。正文为简短原创资料整理，英中对应，标明非全文及非官方译文。

**范围：** 新增 `PubMedReferenceView.vue`、`PaceReferenceView.vue`、`ReferenceTranslationBar.vue` 和 `blogReferences.json`；修改App路由、第三篇资料URL和来源核对文档。不新增依赖，不提交用户原有修改。

验证结果：生产构建102个模块成功；原博客回归脚本及新增资料页脚本均通过。两页中英文切换可完整恢复；资料打开、刷新、目录定位及返回博客可用；390像素英中布局均无横向溢出；页面运行错误与外部请求均为零。检查了两种页面桌面及手机截图。所有博文资料链接均为站内路由。

语言入口调整：两页的语言选择均位于最顶部栏右侧，显示 `English / 中文`，各按钮选择固定语言，当前项加粗并带下划线。正文上方的切换条移除，非官方译文说明并入正文摘要注释。更新后的浏览器检查通过桌面/手机顶部右侧位置、反复选择同一种语言不反向切换、英中内容恢复与原有导航检查，生产构建成功。
